# Kolibri GameDub — Comunidade 🎮🎙️

**Projeto em desenvolvimento. Ainda não há versão pública para download.**

O **Kolibri GameDub** é uma iniciativa para criar **dublagens em português brasileiro de jogos de PC compatíveis**, geradas antecipadamente com inteligência artificial. A meta é jogar com as vozes em PT-BR sem deixar a ferramenta de IA rodando durante a partida.

## Onde estamos

- **Pesquisa de viabilidade:** concluída, com limitações de compatibilidade identificadas.
- **Primeiro marco:** testar qualidade das vozes brasileiras em hardware local.
- **Próximo marco:** dublar e integrar uma cena completa a um jogo/projeto de teste autorizado.
- **Download público:** ainda não disponível; qualquer versão futura será anunciada neste repositório quando estiver apta a testes externos.

## Como participar

Abra uma [Issue](https://github.com/Owls2018/-kolibri-gamedub-community/issues) para indicar um jogo, sugerir recursos ou relatar problemas. Inclua o nome e a versão do jogo, engine se conhecida, se ele suporta mods, e o tipo de áudio (falas separadas ou misturadas com música/efeitos). Evite pedidos duplicados.

O desenvolvimento do motor principal é **privado neste estágio**. Ideias serão avaliadas, mas não substituem o plano de qualidade e segurança da ferramenta.

## Restrições

Não envie arquivos extraídos de jogos comerciais, chaves de licença, cópias de conteúdo protegido ou gravações de terceiros sem autorização. Não apoiamos alterações para burlar DRM/anticheat.

Este repositório contém documentação e espaço para sugestões, **não o código-fonte principal**.
